# Spoiled Catering Booking

Open index.html in a browser. The site uses plain HTML, CSS and JavaScript and runs offline after extraction.

## Demo

1. Open Home and select Plan your event.
2. Select a package, today or a future date, a whole guest count from 20 through 1,000, and an occasion.
3. Toggle the optional add-ons and review the changing summary. Select Prepare request to validate the details.
4. Use sample details on the Login and Sign-up pages. These pages demonstrate form validation. The demo does not create accounts, check availability, or transmit requests.
5. Click the cart illustration at the bottom of any page to open About Us.
